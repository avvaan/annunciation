# Шрифты для печати записок

`DejaVuSerif.ttf` и `DejaVuSerif-Bold.ttf` лежат в репозитории намеренно.

reportlab не умеет woff2, поэтому взять шрифты сайта из `static/fonts/`
нельзя, а на системные полагаться нельзя тем более: базовый образ Render
может приехать без кириллических TTF, и тогда весь лист с именами выйдет
квадратами. Ошибка была бы тихой — PDF собрался бы без единого
исключения. 700 КБ в репозитории надёжнее.

Лицензия — в `LICENSE.txt` (Bitstream Vera / DejaVu, разрешает
распространение). Источник: https://dejavu-fonts.github.io/
